# BEAU — Restaurant Website 🍽️

A modern restaurant website built with React, focused on a clean user interface, an engaging restaurant experience, and responsive design.

## ✨ Features

- Modern restaurant-themed user interface
- Responsive navigation bar
- Light and dark mode support
- Restaurant menu and food cards
- Restaurant detail pages
- Clean and user-friendly layout

## 🛠️ Tech Stack

- **React** — UI development
- **JavaScript** — Application logic
- **CSS** — Styling and layout
- **Vite** — Development server and build tool

## 🚀 Getting Started

Follow these steps to run BEAU locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git (for version control)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/toshifraja137-ship-it/beau-restaurant.git
   ```

2. Navigate into the project folder:

   ```bash
   cd beau
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
